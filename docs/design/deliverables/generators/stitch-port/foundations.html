Foundations — Quartz

MarketCore UI resolves into four deterministic layers: palette → semantic → components → screens. A component names an architectural role (var(--accent)), never a hardcoded hue. Repointing token roles enables multi-theme parity between Light (Quartz) and Dark (Graphite) across both the Seller Console (252px tenant rail) and Buyer Storefront (no rail) without structural drift.
