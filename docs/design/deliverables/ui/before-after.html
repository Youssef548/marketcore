What changed

  • The shell reflows instead of clipping. The rail is one column below lg, so it becomes a full-width block above the content. At 390px the page no longer overflows horizontally (577px → 390px) and the content column is no longer squeezed to 138px. Desktop is untouched: the 252px rail and 768px content are identical at 1440px.
  • The catalog table scrolls instead of hiding columns. The wrapper changed from overflow-hidden to overflow-x-auto, so a wide table is reachable on a phone rather than clipped (88px visible of 299px → 340px of 340px).
  • One heading per page, not two. The top bar already titles the page, so the page-level h1/h2 that repeated the same words were removed — a clean heading outline instead of a duplicated one.
  • The tenant moves to the top bar. The organization the session acts in is now a persistent context strip in the top bar, beside the page it scopes, rather than a box in the rail. The switcher appears only when there is more than one organization to choose from, and the rail is navigation and nothing else.
  • The empty catalog can be filled. An Add product action creates the first product through a new /api/products route, which takes the tenant from the session. The dead-end empty state is gone.
  • Accessibility floor. A skip-to-content link, scope="col" and a caption on the products table, role="status" on the two loading states, a sign-out busy state, and an avatar that reads "A" rather than "A@".
  • The front door names the product. The credential card now carries the application name above it, so a first-timer can see what they are signing into.
